# Documentation Guidelines

1. **Self-Documenting Code**: Use standard docstrings. We use Doxygen-style or Sphinx-style tags (e.g. `@brief`, `@param`, `@details`).
2. **Context Files**: Updates to architecture must be reflected in `.agents/context/` to ensure AI agents have up-to-date knowledge.
3. **Artifacts**: New roadmap features should be documented in `Tasks/` (e.g., `Tasks/backlog/`).
4. **Code Comments**: Keep comments informative (the "why"), avoid explaining the "what" if the code is clear.
