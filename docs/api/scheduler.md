> Applies to Sagittarius Engine v1.x

# Scheduler

The `Scheduler` handles interval and cron-based background scheduling within the Sagittarius Engine runtime.

## Purpose

Use the `Scheduler` to register periodic jobs, cron-based automation steps, or timed triggers.

## Related APIs

- **[TaskManager](task_manager.md)**: Coordinates background threads.
- **[CancellationToken](cancellation_token.md)**: Supports graceful cancellation.
- **[IHostedService](hosted_service.md)**: Exposes a managed running component.
