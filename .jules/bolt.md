## 2024-06-18 - Replacing Recursive Middleware Chains with functools.partial
**Learning:** Python closures/lambdas created in recursive functions can incur a measurable overhead due to state capturing in each frame, specially when chaining heavily (e.g. middleware execution pipelines). Using an iterative approach and `functools.partial` avoids dynamically creating new Python function instances since `partial` is implemented directly in C and flattens out execution.
**Action:** When implementing execution chains or onion patterns where handlers get chained into a final executable callable, prefer iterative `functools.partial` assignment over creating lambdas recursively to reduce object allocation and avoid stack limits.
